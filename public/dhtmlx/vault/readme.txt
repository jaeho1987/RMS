You can import dhtmlxVault into your projects using yarn or npm package manager. To get the trial version of dhtmlxVault, run the following commands:

// yarn
yarn config set @dhx:registry https://npm.dhtmlx.com
yarn add @dhx/trial-vault

Or

// npm
npm config set @dhx:registry https://npm.dhtmlx.com
npm i @dhx/trial-vault
